01 / Campus Reality

打印只是一步，
麻烦在最后一公里。

围绕学生资料打印的完整链条，而不是只优化“点击打印”这一个动作。

↗为一叠资料专门跑一趟打印点与目标楼栋之间存在取件动线。
≋聊天记录里反复确认文件、页码、单双面、份数容易遗漏。
⌕多个文件容易混淆打印后仍要整理、装订、区分归属。
◷什么时候取到不明确预约、改期、交付地点缺少统一记录。
02 / Differentiation

不是否定自助打印，
而是改变服务终点。

无人终端擅长即时、自助与自动收费；本项目聚焦小范围校园楼栋配送、集中加工和低硬件门槛。

差异定位
自助终端优化「一台机器如何无人打印」；DormPrint 优化「资料如何从订单走到校园目标楼栋」。两者各有适用场景，而不是全方位优劣替代。
公开参考（用于描述典型自助工作流，不代表全部市场产品）：南开大学图书馆自助打印 · 华南师范大学自助打印机公告 · 校园自助打印产品说明。

04 / Signature Innovation — Map Selection

地图不是装饰，
是配送业务入口。

校方无须提供复杂地理系统：管理端上传地图、标记可服务楼栋；学生用点选代替模糊文字地址。

01 · 管理员

上传地图，点击布置热点

可调整楼栋名称、类型和是否开放配送；底图更换有版本管理。

02 · 学生

点选一栋，不填门牌

避免楼层/房间隐私采集；热点和文字楼栋列表同步搜索。

交付不是一句“送到了”，
而是可核验的记录。

从订单版本到实体装袋，再到配送员实际交付，每一步都有清晰的操作边界。

DELIVERY PROOF / 履约凭证

配送员提交一次交付记录

仅配送端或管理员端请求设备位置；不要求用户提供个人 GPS。
现场拍照成功上传后纳入交付凭证
真实定位经纬度、精度、采集时间

08 / Roadmap — From Human-in-the-loop to Automation

先跑通“校园履约”，
再走向自助自动化。

V1 降低部署门槛，验证真实需求和运营模型；V2 用软硬件联动逐步替换重复人工操作。

NOW / V1.0 设计方案

人机协作的轻量 MVP

已确定产品方向

先不购买专用自助终端，重点搭建业务链与校园配送调度。

线上提交 / 精确预览多文件、分段、最终 PDF
线下人工核款微信添加好友，管理员确认
人工点击打印打印、装订、装袋检查
楼栋批次配送地图选点、预约时段、交付凭证
价值：少硬件投入，先验证运营闭环
NEXT / V2.0 未来规划

软硬件联动，自助闭环

愿景 / 未实施

在 V1 的订单、定价、版本和批次系统上接入自动执行能力。

自动支付与对账对接合规支付渠道 / 支付回调
打印设备控制网关本地代理 / 打印队列 / 驱动适配
无人值守打印接单自动排队，监测纸张与异常
自助取件 + 校园配送取件码 / 柜机或人工楼栋配送并存
目标：用户提交 → 自动支付 → 自动排版 → 自动出纸 → 取件 / 配送
实现前提：支付服务商资质与接入、目标打印机接口或本地驱动能力、设备状态采集、纸张/耗材监控、失败退款机制与安全运维。V2 为可验证的升级方向，不代表 V1 已具备这些能力。
09 / Why It Matters

让打印不再只是
机器的事。

用校园地图作为地点入口，用批次作为配送组织单位，用订单状态连接数字文件与纸质实物。

这是一套从真实校园场景出发、具备逐步自动化路径的服务产品方案。

先解决最后一公里再迈向全自动
PILOT / 未来试运行关注指标
